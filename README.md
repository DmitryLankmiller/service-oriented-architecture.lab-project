## Создание проекта с помощью `Micronaut`

Для создания проекта используется cli-утилита `mn`. В данной работе используется версия `4.10.18`. Для установки утилиты можно воспользоваться командой:

```sh
sdk install micronaut 4.10.18
```

либо обратиться к официальной документации Micronaut.

Для создания проект используется команда:

```sh
mn create-app ru.ifmo.se.app \
    --features=validation,data-jdbc,postgres,jackson-databind,jackson-xml,lombok \
    --build=gradle \
    --lang=java \
    --jdk=17 \
    --test=junit
```

- `ru.ifmo.se` - базовый package проекта
- `app` - название директории, в которой будет создан проект
- `features` - список библиотек, которые будут добавлены
